RungBars takes a null value for a withheld bar, which stands as an empty column printed with `hidden` ("Hidden" by default) and is counted in the description and table. A bar's `detail` adds a line to its tooltip, `emphasis: null` inks no bar, and `max` sizes the columns' room for a value, so charts set side by side share a scale.
